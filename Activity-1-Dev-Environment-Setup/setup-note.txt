
**Activity 2 – C/C++ Development Environment Setup**

I installed Visual Studio Code, the Microsoft C/C++ extension and MSYS2 MinGW-w64.
Initially, my system was using the older MinGW compiler instead of the MSYS2 compiler.
I checked the compiler paths using the `where.exe gcc` command.
I found that the older MinGW directory had higher priority in the PATH.
I changed the PATH priority to make MSYS2 UCRT64 the default compiler.
I verified GCC and G++ successfully using their version commands.
Finally, I compiled and executed `hello.c` and got the expected "Hello, World!" output.
